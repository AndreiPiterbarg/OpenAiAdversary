# OpenAiAdversary Frontend

Prototype dashboard built with Next.js App Router, TypeScript and Tailwind CSS.

Run the following commands from this directory:

```sh
npm ci
npm run dev
```

To produce a production build:

```sh
npm run build
```

Routes and layouts are in `src/app/`; reusable components are in `src/components/`.
Static example data is in `public/data/`. Read [display notes](ADAPTATION.md) for the
meaning of the example metrics and progress indicators.
