# Execution prompts

Instructions for working with the files in OpenAiAdversary. Use the prompt that matches
the user-authorized task.

| Prompt | Scope |
|---|---|
| [P-CODE](P-CODE.md) | Implement requested behavior. |
| [P-RUN](P-RUN.md) | Run frontend checks and record outcomes. |
| [P-TRAINING](P-TRAINING.md) | Review fine-tuning example displays. |
| [P-CLAIMS](P-CLAIMS.md) | Check user-facing claims against evidence. |
| [P-STATE](P-STATE.md) | Verify checkout state and executed checks. |
| [P-PLAN](P-PLAN.md) | Review scope, paths and completion criteria. |
| [P-DEMO](P-DEMO.md) | Review and demonstrate the prototype interface. |

File paths inside these prompts are relative to the repository root.
