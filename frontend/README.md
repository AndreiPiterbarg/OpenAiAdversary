# OpenAiAdversary Frontend

Next.js App Router starter prepared for hackathon work with shadcn/ui conventions.

## 1) Install dependencies

```bash
npm install
```

## 2) Run locally

```bash
npm run dev
```

## 3) Add shadcn components / blocks

```bash
npx shadcn@latest add button card input
```

If you have access to shadcn blocks, add them with the block command and paste the generated files into `src/components`.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui configuration (`components.json`)
