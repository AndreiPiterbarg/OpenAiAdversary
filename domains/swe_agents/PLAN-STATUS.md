## Completed review round

- Rate estimators reject empty or malformed inputs. Difference intervals use independent-arm
  Newcombe–Wilson bounds with exact boundary handling. Empty detectability reports no power.
- Witness certificates validate counts, required runs, task identity and active clauses.
  Missing or invalid certificates remain in the denominator. Failed bounded witness search
  does not imply impossibility. `unavailable` counts missing/invalid returned certificates;
  failures inside a reference run remain recorded unsuccessful attempts.
- Audit reports require nonempty mutation evidence. The explicit-control executor checks a
  passing baseline, owns fresh sessions, retains every declared case, and treats test errors,
  missing outcomes, invalid patches, session reuse and cleanup failures as unresolved.
